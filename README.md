# Local ancestry-aware association analysis between genetic variants within the progranulin gene and Alzheimers Disease

This repository contains the code used to conduct a local ancestry-aware 
association analyses between genetic variants within the progranulin gene and 
Alzheimers Disease. This analysis was performed using data from the Alzheimer's 
Disease Sequencing Project (ADSP). 

This analysis was conducted as part of a research project aimed at characterizing
the regulatory region surrounding the progranulin gene, and the association of 
its genetic variants with Alzheimer's Disease. The analysis takes into account 
local ancestry information to improve the accuracy of association results.

For further information, please refer to the published 
[manuscript](https://doi.org/10.1186/s40246-026-00958-3): 

  - Life, B.E. & Navarro-Delgado, E.I., et al. Progranulin genetic variant rs5848 
displays ancestry-specific associations with Alzheimer’s disease. 
Hum Genomics (2026). https://doi.org/10.1186/s40246-026-00958-3

## Repository Structure

- `source/`: Contains the R script used for data processing, analysis, and visualization.
- `results/`: Contains the output files generated from the analysis.
